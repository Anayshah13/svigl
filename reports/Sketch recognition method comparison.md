# Pair methods on the same doodles

A Svigl `/research` bake-off on Google Quick, Draw! is **feasible in about a week** if it is a paired scoring harness—not a training campaign, not a 345-way SOTA hunt, and not a claim that Sketch-RNN is a classifier. Freeze **the same drawing IDs** (~**1,100** items to detect a **5-point** top-1 gap at 80% power under independent errors, or ~**470** if methods disagree on only 15% of items), one rasterizer, and Svigl’s existing **normalized exact-match** rule; then score production **Gemini 3.5 Flash-Lite** (open-vocab PNG), a **closed-set stroke RNN**, a **closed-set raster CNN**, **TypeSafe Jev** as a decision-model baseline, and Sketch-RNN only as generation or as an explicitly different recognition hack. Quantifiability comes from **top-1 / top-3 / MAP@3**, **macro-F1**, a **refusal/coverage** triple, **McNemar** plus **paired bootstrap**, and **median/p95 latency plus USD per 1,000 guesses** from usage metadata. Before any call, the operator must supply a **Gemini key**, the **pinned production model ID**, a **USD cap**, a **class-list decision** (game∩QuickDraw vs 20–30 party nouns vs 345-way), and—if Jev is a row—a **TypeSafe key** plus a written image vs stroke-text protocol. A new `frontend/app/research` page can sit beside `/labs` without touching weekly AI-Guesser scoring; bulk inference must **not** reuse `POST /ai-guesser/guess`, which shares the live **800/day** global quota.

## Production Gemini already guesses freely from a 256-pixel PNG

Svigl’s drawing interpreter is a single FastAPI path: `generate_guess` POSTs a raster to Google `generateContent`. The browser never holds the key. The payload is a **PNG** (`inlineData`) plus a short system/user prompt that asks for everyday Pictionary words and structured JSON; it does **not** send stroke JSON, SVG, the secret, or a candidate list. `AiGuessRequest.candidates` is accepted for old clients and never forwarded. Default upstream id is **`gemini-3.5-flash-lite`**, temperature **0.2**, `responseMimeType` `application/json`, **`MEDIA_RESOLUTION_LOW`**, `maxOutputTokens` **224**, thinking **`minimal`**, at most **three** ranked `{answer, confidence}` guesses. Clients see the public label **AnAI 1.3 Pro**. Snapshots are **256×256** white-background PNGs from whiteboard SVG (bot path maps an 800×800 board to the same size). Image bytes are rejected above **200 KB** before the paid call; HTTP timeout is **18 s**. Scoring after the call is closed-set in the game sense: weekly and free-play secrets live in `AI_GUESSER_WORDS`, matched with lowercase, punctuation collapse, and a stripped leading article—the list is never shown to Gemini. Frontend shout requires confidence **≥ 0.3**; the room bot uses **0.5**. That split is product policy, not a model difference. Rate limits default to **15/min/IP**, **150/day/IP**, **800/day global**, **4 s** debounce, **12** looks per turn. A research page that only scores drawings can keep the whiteboard, `shapesToSvgMarkup`, and `generate_guess` **without** `run_id`, weekly clocks, TTS, or AnAI shout UI. There is **no `/research` route today**; `/labs` is geometry precision, not recognition. Putting the bake-off under Labs would collide with that meaning. Reusing `/ai-guesser/guess` for thousands of QuickDraw rasters would starve the live demo.

This method is therefore **open-vocabulary vision plus lexical exact match against a hidden closed set**. A fair table needs a second Gemini row if the study also asks the model to choose among named classes (CLIP-style closed-set). Mixing those two into one accuracy number answers a different question than “what does Svigl actually ship?” Gemini Developer API list price for this Flash-Lite tier is **$0.30 / 1M input** and **$2.50 / 1M output** on Standard, including thinking ([Gemini Developer API pricing](https://ai.google.dev/gemini-api/docs/pricing)). Gemini 3 image tokens at low media resolution are **280** versus **1,120** at the unspecified/high default ([Gemini media resolution](https://ai.google.dev/gemini-api/docs/media-resolution)). A back-of-envelope Flash-Lite call with a default-resolution image plus short text is on the order of **$0.60 per 1,000 guesses**; production already chooses **low** resolution, so the empirical cost should land lower, and must be taken from `usageMetadata`, not this illustration. Residual web-pretraining contamination of QuickDraw doodles cannot be ruled out for Gemini or Jev.

## Sketch-RNN generates ink; RNNs and CNNs name classes

Collapsing “RNNs, SketchRNN, CNNs” into one detection family is a category error. Google’s public Quick, Draw! **classifier** recipe is a **stroke-sequence** model: points `(x, y, stroke-start)`, 1-D convolutions, **bidirectional LSTM**, softmax over **345** classes, with the TensorFlow tutorial claiming **~70% top-1 after 1M steps**—enough for a game that lets players keep drawing and accepts a class above a score threshold, not only top-1 ([TensorFlow r1 recurrent_quickdraw](https://github.com/tensorflow/docs/blob/master/site/en/r1/tutorials/sequences/recurrent_quickdraw.md)). An independent 2018 reproduction of the default script reported **~55%** and rising eval loss ([tensorflow/models#5114](https://github.com/tensorflow/models/issues/5114)). **No official 345-way RNN checkpoint** is sitting on a 2026 pip install. The 2016 GRU “Pictionary” paper at **85.1%** is **160-class TU-Berlin**, not QuickDraw, and must not be quoted as a 345-way number ([arXiv:1608.03369](https://arxiv.org/abs/1608.03369)). On the 2018 Kaggle challenge (**340** classes, **MAP@3**), first-place **LSTM** scored **0.893** against a best single **CNN 0.946** ([1st place writeup](https://www.kaggle.com/competitions/quickdraw-doodle-recognition/writeups/ods-ai-pablos-1st-place-solution)).

**Sketch-RNN** (Ha and Eck) is a seq2seq **VAE** that emits the next **(Δx, Δy)** from a **20-component GMM** and a **3-way pen** (draw / lift / end). The paper reports reconstruction and KL, interpolations, and completions—**not classification accuracy**. Authors state it is **ineffective at modelling many classes at once**; a 75-class unconditional model mixed features across categories ([arXiv:1704.03477](https://arxiv.org/abs/1704.03477)). Magenta still documents TF 1.0–1.1 / Python 2.7 checkpoints plus a JS port with **~100** JSON weight files on GCS ([magenta sketch_rnn README](https://github.com/magenta/magenta/blob/main/magenta/models/sketch_rnn/README.md); [sketch-rnn-js](https://github.com/magenta/magenta-demos/blob/main/sketch-rnn-js/README.md)). A third-party fork that **replaces the decoder with a linear classifier** reports **92%** on **16** QuickDraw classes—that is an encoder-as-classifier, not released Sketch-RNN ([payalbajaj/sketch_rnn_classification](https://github.com/payalbajaj/sketch_rnn_classification)). Class-conditional likelihood **argmax_c p(x|c)** is a legitimate research hack because Magenta ships **per-class** generators, but **no sourced QuickDraw top-1** exists for that procedure, and it costs **C** RNN forwards per sketch. For a one-week page, keep Sketch-RNN in a **generation / completion** panel, or drop it from the classifier table unless a pretrained **stroke classifier** (not the Magenta generator) is loaded.

Raster **CNNs** are closed-set softmax on bitmaps. Google’s official rasters are **28×28** grayscale from simplified strokes, **bbox-centered**, unlike top-left-aligned simplified ndjson ([quickdraw-dataset README](https://github.com/googlecreativelab/quickdraw-dataset/blob/master/README.md)). Tutorial nets land around **65.57% top-1 / 82.71% top-3** at 345-way with 4k train / 1k test per class, and **89.76% / 95.34%** at 20-way ([jtheiner/SketchRecognition](https://github.com/jtheiner/SketchRecognition)). An unofficial TFLite SE-ResNet self-reports **76.19% top-1** at 345-way with 8k samples/class ([zarqankhn/quickdraw-345-tflite](https://huggingface.co/zarqankhn/quickdraw-345-tflite)). Stanford CS229 saw **~82%** on 50 classes with 20k examples/class on 28×28 ([CS229 report 33](https://cs229.stanford.edu/proj2018/report/33.pdf)). Kaggle SOTA is a different sport: ImageNet-pretrained SE-ResNeXt-class models on **128–256 px** rasters, often with **stroke-order or timing channels**, **MAP@3 ~0.95** on 340 classes; one strong single model’s local **top-1** was **86.48%** ([5th place](https://www.kaggle.com/competitions/quickdraw-doodle-recognition/writeups/ods-ai-resnet34-5th-place-solution); [8th place](https://www.kaggle.com/competitions/quickdraw-doodle-recognition/writeups/aleksey-nozdryn-plotnicki-8th-place-novel-solution)). Do not cite **0.95 MAP@3** as 28×28 CNN top-1. Chance at 345-way is ~**0.3%** top-1 ([CS229 report 98](https://cs229.stanford.edu/proj2018/report/98.pdf)). A Keras MNIST-style net is a fair **closed-set baseline** for a side project; it is **not** a stand-in for Kaggle gold and **cannot** name classes outside its softmax. Training 345-way toward Kaggle quality needs GPU and large disk (one MobileNet pass on 50M drawings was reported as **20 h** on a Tesla P100 and **$50** GCP ([Doodling with Deep Learning](https://medium.com/data-science/doodling-with-deep-learning-1b0e11b858aa))). Inference of an 8 MB TFLite 345-way net is CPU-plausible for a few thousand images. **Out of scope for one week:** from-scratch Sketch-RNN, full 50M inference, human re-label, 5×2 CV retraining (Dietterich’s test is for algorithms that can be retrained ten times, not frozen APIs ([Dietterich 1998](https://doi.org/10.1162/089976698300017197))), and UI polish beyond a thin research page.

## Quick, Draw! is prompt-supervised noise you can download this afternoon

The public dump is still the **May 2017** GCS bucket `quickdraw_dataset`: **50,426,266** drawings, **345** prompt categories, CC BY 4.0 ([Hugging Face google/quickdraw](https://huggingface.co/datasets/google/quickdraw); [LICENSE](https://github.com/googlecreativelab/quickdraw-dataset/blob/master/LICENSE)). Object timestamps on sampled files have not moved since 18–25 May 2017. The label `word` is **what the player was asked to draw**, not a human visual judgment; `recognized` records whether the **in-game classifier** accepted the doodle. Google’s own taxonomy of that noise is four-way: finished and recognized late; **correct but incomplete** because the game stopped early (common among `recognized=true`); correct but never recognized; **wrong concept** (seesaw vs saw) ([Google Research Kaggle intro](https://research.google/blog/introducing-the-kaggle-quick-draw-doodle-recognition-challenge/)). Colin Morris’s flamingo study shows scribbles, cheats, and off-category drawings inside a single prompt file; the public gallery is cleaner than the download ([Finding bad flamingo drawings](https://colinmorris.github.io/blog/bad_flamingos)). Accuracy against `word` answers “did we recover the prompt?”, which is the original game target.

Kaggle used **340** classes and a **manually labeled, shifted** test scored with **MAP@3**; the contest bundle is **244.4 GB** under competition rules, not CC BY ([Kaggle overview](https://www.kaggle.com/competitions/quickdraw-doodle-recognition/overview)). Do not mix 345-class GCS files with Kaggle MAP@3 numbers. Hugging Face `raw` / simplified / bitmap configs put **all 50.4M rows in `train`**—there is **no** official test split there. Magenta Sketch-RNN `.npz` files **do** ship **70,000 / 2,500 / 2,500** per class (24.15M / 862.5k / 862.5k over 345). Those `.npz` files commonly **omit `key_id`**, so pairing with raw ndjson is not automatic; treat the npz test split as an opaque held-out set rather than fuzzy-matching strokes back onto the full dump.

Storage: simplified ndjson and 28×28 numpy are on the order of **~25–40 GB** for all 345 classes; raw ndjson extrapolates near **~170 GB**. A 30-class Sketch-RNN `.npz` pack is about **420 MB** (`cat.npz` is 14.8 MB). Thirty full 28×28 `.npy` files are ~**3 GB**. HTTPS still serves `https://storage.googleapis.com/quickdraw_dataset/sketchrnn/{class}.npz` and `full/numpy_bitmap/{class}.npy` without `gsutil`. **Afternoon plan:** pick **20–30** concrete party nouns (`cat`, `dog`, `fish`, `house`, `car`, …), skip geometric primitives, landmarks, and homonyms, download `.npz`, rasterize those **test** strokes with one frozen renderer (canvas, line width, polarity, centering), and score every method on that ID list. Do not assume `.npy` row order matches Sketch-RNN test IDs. CC BY 4.0 allows a personal benchmark, subset redistribution with attribution, and sending rasters to third-party APIs; it does **not** license the Quick, Draw! trademark or waive Gemini/TypeSafe terms ([SPDX CC-BY-4.0](https://spdx.org/licenses/CC-BY-4.0.html)). Prefer GCS/HF over Kaggle for a side project.

## Quantify with frozen IDs, exact match, McNemar, and paid-call accounting

Headline metric is **top-1** on a frozen paired set, refuse counted wrong (game-relevant). Also report **top-3** and **MAP@3** (hit at rank 1/2/3 scores 1, 1/2, 1/3) because Svigl already returns three guesses and Kaggle used that formula. **Macro-F1** is required whenever class support is uneven or the table mixes a 20-way game subset with 345-way closed-set nets; with equal *n* per class, top-1 equals micro-accuracy, but macro-F1 still uses precision. Any method that can abstain needs **refusal rate**, **coverage**, and **selective accuracy** on the accepted subset; folding abstentions into ordinary accuracy distorts the comparison ([El-Yaniv & Wiener, JMLR 2010](https://jmlr.org/papers/volume11/el-yaniv10a/el-yaniv10a.pdf)). Closed-set softmax almost never refuses unless a confidence threshold is added; apply the **same** threshold policy to every method that can stay silent, including Svigl’s 0.3 vs 0.5 shout floors if those are in-scope.

Map Gemini free text with the **production normalizer and exact string equality** to the canonical QuickDraw `word`. That is the conservative VQA practice ([VQA evaluation](https://visualqa.org/evaluation.html)). A frozen synonym table or a named sentence-embedder with a pre-registered cosine τ belongs in an **appendix sensitivity** table on the same IDs, never as the headline: fuzzy credit inflates open-vocab rows and can merge distinct classes such as cake vs birthday cake ([CS229 report 98](https://cs229.stanford.edu/proj2018/report/98.pdf)). CLIP-style scoring of every class name is a **different method**, not a post-hoc gift to Gemini ([OpenAI CLIP](https://openai.com/index/clip/)).

Pairing means **shared `key_id`s**, not shared tensors. Stroke RNNs consume ordered offsets; CNNs, Gemini, and Jev-image consume pixels. Write a **rasterization card** once (simplified vs raw; canvas; stroke width; anti-alias; padding; hash of each PNG) and reuse those bytes. Google notes that **stroke order and direction** often beat static images for handwriting-style recognition ([Google Research Kaggle intro](https://research.google/blog/introducing-the-kaggle-quick-draw-doodle-recognition-challenge/)); Kaggle fifth place gained public LB by encoding delay, draw time, and stroke count as extra channels ([5th place writeup](https://www.kaggle.com/competitions/quickdraw-doodle-recognition/writeups/ods-ai-resnet34-5th-place-solution)). A 28×28 CNN and a stroke LSTM are still paired on **difficulty**, not on representation.

For two already-trained (or API) systems on one test set, **McNemar** (exact binomial on discordant pairs when *n*01+*n*10 < 25) is the test Dietterich recommends; two-proportion z-tests and paired t-tests over random splits inflate Type I error ([Dietterich 1998](https://web.engr.oregonstate.edu/~tgd/publications/dietterich-approximate-statistical-tests-nc1998.pdf)). Connor’s paired-proportion sample size for δ = 0.05, α = 0.05, 80% power is **N ≈ 1,097** if errors were independent at 80% vs 75% accuracy, and **N ≈ 469** if disagreement ψ = 0.15 ([Dackohn sample-size tool](https://dackohn.com/stats/tools/llm-eval-sample-size.html)). Budget **N ≥ 1,100** plus a 100–200 pilot to measure ψ. Stratify: 20 classes × 60 drawings = 1,200. Full 345-way at N = 1,100 is ~**3** drawings/class—usable for global Acc1, **useless** for macro-F1; that needs **10–20 per class** (N = 3,450–6,900). Holm–Bonferroni the pairwise McNemars, or publish bootstrap CIs on each δ without crowning a tournament. Paired bootstrap (10k resamples of glued outcomes) covers Acc1 and macro-F1. Pre-register the ID list, seed (default **20261027** if unspecified), `recognized` filter, and matching rule. **Never** score a CNN on public IDs if its card says it trained on all QuickDraw; then hold out unseen classes, collect new drawings, or drop the checkpoint.

Secondary metrics for a game: **median and p95 latency** from bytes-in to parsed guesses (include live rasterization, exclude dataset I/O, cold-start the first call separately); **USD/1,000** from actual token fields; timeout/error rate. Primary accuracy should use **final stored strokes**; in-progress prefixes reconstructed from raw timestamps `t` are an optional slice, because public `recognized=true` finals are an optimistic mix of complete and truncated doodles.

## Jev is a typed decision API, not a doodle specialist

The matching product is **TypeSafe AI’s Jev**, a proprietary “System One” model announced **15 September 2026**, current pin **`jev-1.14.0`** (`jev-latest` as of late October 2026), API `POST https://api.typesafe.ai/v1/systemone` ([TypeSafe](https://typesafe.ai/); [models](https://docs.typesafe.ai/models)). It returns **Choice / Score / Noul** (and experimental Box)—typed answers and probabilities, no generated strings ([System One](https://docs.typesafe.ai/concepts/system-one)). Sketch **classification** maps onto Choice with caller-supplied class names (up to **255** options). It is **not** JEPA, not `jev.ai` (parked), and not OpenJev/Kev/Laya clones. There are **no local TypeSafe weights**; MCA forbids distillation into a competing sketch model ([MCA](https://typesafe.ai/legal/mca)).

Production input is **text**. Images are an opt-in preview (`TypeSafe-Danger-Zone-Images: true`): PNG/JPEG stills, **280–1568 px** per side, no server-side resize, billed as input tokens, and TypeSafe states models **perform worse on multimodality than on text** ([Images](https://docs.typesafe.ai/go/images); [Jev 1.14](https://typesafe.ai/blog/jev-1-14)). QuickDraw 28×28 or 256 px rasters **must be padded by the caller**. Independent NLP numbers (IMDB 96.5%, HellaSwag 95.5%, Choice ECE 0.028 on 37 datasets) are **text decision tasks**, not sketches ([arXiv:2609.37647](https://arxiv.org/html/2609.37647v1)). The only public doodle study found—Mikulski, 400 Google-recognized drawings, 10 classes, **before** the image header—got Jev on **SVG text ~35%** and on **base64 PNG-as-text ~9%**, versus Sonnet **looking at the image ~91%**, with heavy airplane bias ([Mikulski](https://mikulskibartosz.name/typesafe-jev-guess-what-i-drew)). A later n=11 gist of canvas PNGs is not a QuickDraw result.

List price is **$0.042 per million input tokens**, output free ([models](https://docs.typesafe.ai/models)). New accounts since **27 September 2026** get **no free credits**. Services are **US-hosted**; default retention is not zero (ZDR is enterprise). Latency vendor-claim is **70–500 ms**. Include Jev as **two labeled rows if budget allows**: (A) stroke JSON/SVG as `state`; (B) padded PNG + danger-zone header on pinned `jev-1.14.0`. Do not average them. If the scientific claim is only “vision LM vs sketch CNN,” Jev is optional. If the claim is “do we still need a generative LM to pick a class?,” Jev is the on-topic non-generative arm.

**What blocks the first run:** a Gemini key that can call vision `generateContent` and survive *N* retries; the **exact** production model string; a hard **USD cap** (example floor ~$1 for 1,200 low-res Flash-Lite looks, set something like **$20** because thinking and resolution dominate); **C** (intersection of game words with QuickDraw vs a 20–30 class subset vs 345-way); Jev key and modality only if that row is in. **Freeze before scoring:** open-vocab vs list-constrained Gemini as separate methods; whether `recognized=false` is included; CNN/RNN checkpoint cards for leakage; Gemini `media_resolution`. Optional: seed, larger *N*, Sketch-RNN as generator-only vs likelihood. ## Conclusion

The interesting result this page can actually produce is not “which architecture is best at sketch recognition,” but **how much accuracy, latency, and money Svigl’s open-vocab Flash-Lite call spends relative to a closed-set doodle specialist and a typed decision model on the same noisy prompts**. Sketch-RNN stays in the story as a reminder that Magenta solved **motor generation**, not guessing; forcing it into the accuracy table without a documented classifier head would manufacture a fake peer. Once IDs, matcher, and raster hashes are artifacts, adding a method later is another column, not another dataset—and that is the whole point of putting the study on `/research` instead of inside the live 800-looks-a-day guesser.
